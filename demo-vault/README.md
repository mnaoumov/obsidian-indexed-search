# Indexed Search demo vault

This is an [Obsidian](https://obsidian.md/) vault demonstrating features of the [Indexed Search](https://github.com/mnaoumov/obsidian-indexed-search) plugin.

## Opening this vault

- **If you already have the plugin installed**, run the **`Indexed Search`: Open demo vault** command — it downloads and opens the latest demo vault automatically.
- **Otherwise**, download `indexed-search-demo-vault.zip` from the [plugin releases](https://github.com/mnaoumov/obsidian-indexed-search/releases), unzip it, and in Obsidian choose `Manage vaults...` → `Open folder as vault` → select the `indexed-search-demo-vault-<version>` folder it unzips into.

On first open, Obsidian treats the vault as untrusted — choose **Trust author and enable plugins** (or enable Community plugins manually), then open [00 Start](<./00 Start.md>).
